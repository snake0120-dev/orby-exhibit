ORBY 전시용 자동재생 화면 — 세팅 안내
천우태 졸업전시


■ 여는 법

   index.html 을 더블클릭하면 끝입니다.

   인터넷이 없어도 됩니다. 글꼴·사진·코드가 전부 이 폴더 안에
   들어 있어서, 랜선을 뽑아놔도 똑같이 돌아갑니다.

   USB로 옮길 때는 이 폴더를 통째로 복사하세요.
   안의 파일 하나만 빼내면 열리지 않습니다.


■ 전체화면으로 만들기

   사파리 : 열고 나서  control + command + F
   크롬   : 열고 나서  control + command + F

   메뉴 막대와 독이 사라지고 화면만 남습니다.
   빠져나올 때도 같은 키입니다.


■ 돌아가는 방식

   네 장이 8초씩, 32초에 한 바퀴를 돕니다.
   끝나면 처음으로 돌아가 계속 반복합니다.
   관객이 뭘 누를 필요도, 누를 것도 없습니다.

      1장  표지 — 비동반 소아 서비스
      2장  Pain Point
      3장  솔루션 01 · 웨이파인딩 서비스
      4장  솔루션 02 · 예습 게임


■ 화면이 꺼지지 않게

   페이지가 알아서 절전을 막습니다. 다만 맥 설정이 더 강하면
   그쪽이 이기므로, 전시 전에 한 번 꺼두는 편이 안전합니다.

      시스템 설정 → 디스플레이 → 고급 →
      "디스플레이가 꺼져 있을 때 자동으로 잠자기 방지" 켜기

   화면 보호기도 꺼두세요.

      시스템 설정 → 잠금 화면 →
      "화면 보호기 시작 시간" 을 '안 함' 으로


■ 문제가 생기면

   화면이 멈췄다      →  command + R 로 새로고침
   글자가 이상하다     →  폴더를 통째로 복사했는지 확인
   화면이 잘려 보인다  →  전체화면으로 들어갔는지 확인

   대부분 새로고침 한 번이면 해결됩니다.
   몇 시간을 틀어놔도 시간이 밀리지 않게 만들어뒀습니다.


■ 고치고 싶을 때

   속도를 바꾸려면  assets/js/show.js 의 맨 위
   HOLD 값(8000)을 고치면 됩니다. 단위는 밀리초입니다.
   12초로 늘리려면 12000 으로 바꾸고 저장하세요.
